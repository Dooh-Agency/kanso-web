# Inputs

Material para las tandas: fotos de piezas y proyectos, novedades, fechas especiales e indicaciones del equipo. Una subcarpeta por tema, por ejemplo `2026-11-16-merope/`. Cada input indica fecha, cliente o proyecto, qué está autorizado para comunicar y restricciones.

Las fotos pesadas van en Google Drive; acá se deja el link.
